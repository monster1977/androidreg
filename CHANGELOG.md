# Журнал версий — Dashcam (Авторегистратор)

## Правило версионности

Перед каждой release-сборкой **самостоятельно** повышать две строки в `app/build.gradle`:

```groovy
versionCode  <старый + 1>   // целое число, всегда растёт, нужно Android/Play
versionName  "<старый + 1>" // видимая версия вида "1.16"
```

- `versionName` — по схеме `MAJOR.MINOR`, MINOR растёт на 1 с каждой сборкой
  (MAJOR — только при крупных изменениях).
- Сборка: `gradlew :app:assembleRelease -PtargetSdk=30`
  (ключ `-PtargetSdk=30` — Android 11, обход ограничений Android 12+ для
  автозаписи из фона; для Play нужен targetSdk 34+ без этого ключа).
- Release-APK автоматически копируется в `dist/` — там лежат **все** прошлые
  версии, они не удаляются и не затираются. Структура:
  `dist/dashcam-v<versionName>-release.apk`.
- `build/` — служебный каталог, очищается Gradle, старые сборки там не живут.

## Репозиторий

- 2026-10-29: исходники перенесены в Git, публичный репозиторий
  `https://github.com/monster1977/androidreg` (ветка `main`).
- `dist/`, `keystore/`, `keystore.properties`, `local.properties`, `build/`, `.gradle/`
  в репозиторий не попадают (`.gitignore`).
- Ключ 2ГИС Geocoder хранится только в `local.properties` (`TWOGIS_KEY`) и попадает в
  `BuildConfig.TWOGIS_KEY`; в исходниках и истории его нет. Без ключа сборка компилируется,
  но геокодер попросит ключ в настройках.
